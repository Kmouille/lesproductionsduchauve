# Guide Pages CMS - Les Productions du Chauve

Toutes les modifications se font sur https://app.pagescms.org avec ton compte GitHub.
Chaque enregistrement met le site à jour en une minute environ. Chaque champ a une petite
aide sous son nom.

## Ajouter une production

1. Menu **Productions**, bouton **Ajouter**.
2. **Titre** et **Artiste**.
3. **Pochette** : envoie le fichier fourni par le groupe, le plus grand possible (3000 px
   c'est parfait, 1400 px minimum). Le site s'occupe de l'alléger.
4. **Date de sortie** : seule l'année s'affiche, la date sert à trier.
5. **Lien d'écoute** : colle l'adresse de l'album (Bandcamp, SoundCloud, YouTube, Spotify
   ou autre). Le site affiche un bouton "Écouter sur ...".
6. **Résumé** : 200 caractères maximum, c'est le texte au dos de la pochette.
7. **Mon rôle** : coche au moins un rôle, sinon la production ne peut pas être publiée.
8. **Genres** : choisis dans la liste. Il en manque un ? Demande à Camille.
9. **Texte** (facultatif) : raconte la session, le matériel, les anecdotes.
10. **Autres liens** (facultatif) : site du groupe, clip, article.
11. **À la une** : coche pour la montrer sur la page d'accueil (4 maximum, les plus
    récentes).
12. **Brouillon** : coche tant que ce n'est pas prêt. Décoche pour publier.
13. **Enregistrer**.

## Les brouillons déjà importés

Les sorties Bandcamp ont été importées en brouillon. Pour chacune : vérifie le titre,
l'artiste et le résumé, coche tes rôles et les genres, remplace la pochette si tu as un
meilleur fichier, puis décoche **Brouillon**.

## Modifier les pages

| Menu                 | Ce que tu peux changer                                         |
| -------------------- | -------------------------------------------------------------- |
| **Accueil**          | La photo principale et les lignes de texte du bandeau          |
| **Qui suis-je**      | Ton portrait et ton histoire                                   |
| **Le studio**        | Deux blocs, Le studio et Le matériel : un texte et 12 photos   |
| **Services**         | Le titre, l'accroche et la description des 5 services          |
| **Réglages du site** | L'email de contact, les réseaux sociaux, la description Google |

## Si le site ne se met pas à jour

Une erreur dans une fiche (par exemple une production publiée sans rôle) bloque la mise à
jour, mais le site en ligne reste tel quel. Préviens Camille avec le nom de la fiche.
